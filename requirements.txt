# 实测 2.9.1。macOS 上的下界由 bf16-on-MPS 支持决定(见 models/dinov3.py 纪律 5:
# ViT-H+ 深层激活峰值 34720,fp16 上限 65504,余量仅 1.9 倍,必须用 bf16)。
torch>=2.4,<3

# 不是可选的。transformers 的 DINOv3ViTImageProcessorFast 声明
# @requires(backends=("torchvision", "torch")),缺了它 AutoImageProcessor 直接失败。
torchvision>=0.18

# 4.57.6 实测通过。上界锁 <5:5.x 是大版本跳跃,本项目依赖 modeling_dinov3_vit 的
# 具体行为(hidden_states 未过 final norm、tie_last_hidden_states=False、
# token 布局 [CLS|registers|patches]),不确认过不要升。
transformers>=4.57,<5

# **这一条最容易踩坑。** transformers 4.x 硬约束 huggingface-hub>=0.34.0,<1.0。
# 直接 `pip install -U huggingface_hub[cli]` 会装到 1.x,然后 import transformers
# 当场 ImportError。装 CLI 请用:pip install "huggingface_hub[cli]<1.0"
huggingface-hub>=0.34,<1.0

numpy>=1.24,<3
pillow>=10.0
tqdm>=4.65
